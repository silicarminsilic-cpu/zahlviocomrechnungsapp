# Zahlvio

Rechnungs-Software für Unternehmen in der Schweiz, Deutschland und Österreich. Betreiberin: Esche Consulting GmbH, Vaduz.

**Dieses Repository muss privat bleiben.** Es enthält nie Geheimnisse oder Kundendaten.

## Aktueller Stand (Hauptordner)

Start ohne Konto-Backend: Website, Live-Demo und Kontaktformular (`kontakt.php`). Anleitung zum Hochladen: `HOCHLADEN.md`.

## Backend (Ordner `backend/`, noch nicht ausgeliefert)

Die Version mit Registrierung, Login und Datenbank (PHP 8.1+, SQLite), die verschlüsselte Datensicherung und die Vorlage für das automatische Deployen aus GitHub (`backend/workflow/deploy.yml`, nach `.github/workflows/` verschieben, wenn die Secrets eingetragen sind). Einrichtung: `backend/DEPLOY.md`.
